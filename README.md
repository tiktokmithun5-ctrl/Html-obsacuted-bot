# 𝐃𝐄𝐕𝐋𝐎𝐏𝐄𝐑 𝐅𝐈𝐀𝐂𝐁 𝐁𝐃 — Telegram HTML Protector

Install:
pip install -r requirements.txt

Set your Telegram BotFather token as BOT_TOKEN, then:
python bot.py

Send an HTML file to the bot; it returns a protected/obfuscated HTML file.

Note: browser-side obfuscation is not unbreakable. The browser must eventually decode/render the content, so this is deterrence rather than absolute secrecy.
